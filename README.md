# Mell Alderete — Portafolio

Coffee Educator & Beverage Developer · Specialty Coffee · Education · Beverage Innovation

Sitio estático de una sola página (ES / EN). Todos los archivos están en la raíz, sin carpetas.

## Publicar en GitHub Pages
1. Sube todos los archivos de esta carpeta a la raíz del repositorio.
2. Ve a **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. En un par de minutos el sitio queda en `https://<usuario>.github.io/<repositorio>/`.

## Pendiente antes de publicar
- Reemplazar `correo@ejemplo.com` por el correo profesional real.
- Poner los enlaces de Instagram y LinkedIn (buscar `[@usuario]` y `[perfil LinkedIn]` en `index.html`).

## Tecnología
HTML + CSS + JavaScript sin build. Animaciones con GSAP 3.12.5 (ScrollTrigger, Flip) y Lenis 1.1.13 desde CDN.
